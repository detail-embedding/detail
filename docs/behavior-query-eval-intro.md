# Behavior-query evaluation

Behavior-query evaluation generates accuracy scores for behavior retrieval based on user-provided
ground-truth labels. Randomly selected instances of behavior are held-out and used as queries. Point
and state annotations are supported. Metrics can be averaged over several iterations of evaluation
using different query instances.
