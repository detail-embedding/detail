The cluster profile says which measures set one cluster apart from the rest of the run (or from
its sibling in the tree, or from another cluster you name), and how far to trust that. Where the
animal is and which way it faces are measured but left out unless you ask for them. It draws a random sample of the cluster's
members and as many to compare against, measures both, and fits a small model. The model is
always scored on recordings it has not seen, beside a floor: the same fit with the cluster's
members shuffled. When the score does not clear the floor by the margin, the measures do not
separate the cluster, and the profile says so before showing anything else.

Open it from a clustering run's INTERPRET (**Cluster tools ▾ › Cluster profile…**, or right-click a
block on the tree, **Cluster profile…**) or from the clip window's **Cluster details**; or run `detail analysis profile`. Your
labels are never used: the profile explains the clustering, not your names for it.
