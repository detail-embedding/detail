Behavior-query evaluation scores how well the behavior query retrieves a labeled behavior against
your ground-truth labels. Held-out example clips seed the query, and the remaining labeled
instances are the answer.

[Behavior-query evaluation](../behavior-query-eval.md) covers the matching rule and every metric
this module reports.
